레퍼런스 찾기 1차 컨펌 리뷰

API 키 설정

이 도구는 본인의 Anthropic API 키로 동작합니다. 키는 이 브라우저에만 저장되고 서버에는 저장되지 않으며, 요청할 때마다 본인 계정의 사용량으로만 청구됩니다.

API 키가 없다면 console.anthropic.com에서 발급받을 수 있습니다.

1 분석 시작하기

검토할 시안 스크린샷을 첨부하면 오른쪽에서 스캔 과정을 확인할 수 있습니다.

이미지를 드래그하거나 클릭해서 업로드
(또는 캡처 후 Ctrl+V / Cmd+V)

2 이미지 스캔

이미지를 첨부하고 '분석 시작하기'를 누르면 여기서 스캔 과정을 확인할 수 있습니다.

대기 중
스캔 중입니다...

    컨펌자에게 넘기기 전, AI 초안을 스스로 점검하고 피드백을 받아보세요.

    1 제안 결과물

    앞에서 첨부한 이미지가 여기 표시됩니다. 필요하면 더 추가하거나 뺄 수 있습니다.

    이미지를 드래그하거나 클릭해서 추가 업로드

    2 이미지 주석 리포트

    Claude가 첨부한 시안을 디자인 관점에서 분석해 이미지 위에 번호로 표시합니다. 번호를 클릭하면 오른쪽 설명이, 설명을 클릭하면 이미지 위 번호가 강조됩니다.

    AI가 시안을 분석하는 중입니다... (몇십 초 걸릴 수 있어요)
    미흡 보완 필요
    3 자가 체크리스트 선택사항 · 펼쳐서 진행

    항목별로 상태를 선택하세요. 양호 / 보완필요 / 미흡 · 코멘트는 선택 입력입니다.

    4 종합 의견

    자가 체크리스트를 체크하면 아래 결과와 의견이 자동으로 갱신됩니다.

    체크리스트 입력 내용은 자동 저장됩니다 (업로드한 이미지는 용량 문제로 다시 열 때 재첨부가 필요합니다).
